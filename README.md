# 🎮 4tikoTool

أداة **4tikoTool** مصممة لصنّاع محتوى الألعاب والمونتاج الذين يرغبون في سلاسة أعلى ونتيجة أنظف عند الرفع على تيك توك.

تقوم الأداة برفع الإطارات (Interpolation) باستخدام RIFE ثم تصدر لك ملف TikTok جاهز للرفع.

---

## ✨ أهم المميزات

- 🚀 تحويل 60FPS إلى 120FPS بسلاسة (x2 – مقفلة عندك على 1 Pass)
- 📦 إخراج ملفين:
  - ملف PC بجودة CRF للمشاهدة/الأرشفة
  - ملف TikTok Base + ملف TikTok Patched جاهز للرفع
- 🎬 تعتمد على محرك FFmpeg في الترميز لضمان توافق واسع مع المشغلات والمنصات
- 🖥️ واجهة بسيطة: اختر الفيديو، اختر مسار الإخراج، واضغط Start

---

## 🎯 مناسب لـ

## 🚀 طريقة الاستخدام (سريعة)

1. **Input:** اختر الفيديو
2. **Output:** اختر اسم ملف الإخراج
3. **Patch:** فعّل/اقفل Patch حسب رغبتك
4. **Start:** اضغط Start لبدء العملية
5. **الرفع:** ارفع الملف `*_TT_120_PATCHED_60.mp4` إلى TikTok
